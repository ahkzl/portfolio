# ahyanakizilaslan.de

Portfolio-Website von Ahyana Kizilaslan. Statische Seite, kein Build-Schritt.

## Inhalt

| Datei / Ordner | Bedeutung |
| --- | --- |
| `index.html` | Die komplette Seite: Aufbau, Gestaltung und alle Texte in Deutsch und Englisch |
| `support.js` | Technischer Unterbau, der die Seite zusammensetzt. Nicht bearbeiten |
| `uploads/` | Alle Bilder, GIFs und der Lebenslauf als PDF |
| `fonts/` | Die beiden Schriftarten, lokal eingebunden |
| `favicon.svg` | Das kleine Symbol im Browser-Tab |
| `CNAME` | Enthält die Domain. Nicht löschen, sonst fällt die Domain weg |
| `.nojekyll` | Sorgt dafür, dass GitHub alle Dateien unverändert ausliefert |

## Text ändern

`index.html` öffnen, mit Strg+F den Satz suchen, den du ändern willst. Alle Texte
stehen gesammelt in einem Block: zuerst die englische Fassung (`en:`), darunter die
deutsche (`de:`). Nur den Text zwischen den Anführungszeichen ändern, Anführungszeichen
und Komma stehen lassen.

## Bild austauschen

Neue Datei in `uploads/` hochladen. Trägt sie denselben Namen wie die alte, ist nichts
weiter zu tun. Bei einem neuen Namen den alten Dateinamen in `index.html` suchen und
ersetzen.

## Lebenslauf aktualisieren

Neue PDF unter dem Namen `Resume_Ahyana_Kizilaslan.pdf` in `uploads/` hochladen.
